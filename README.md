Python Data Types

This repository contains simple examples of Python data types for learning and practice.

📚 Topics Covered

- Lists
- Tuples
- Sets
- Dictionaries

📁 Project Structure

- basics/list.py → List examples
- basics/sets.py → Set examples
- tuples/num_tuple.py → Tuple examples
- examples/countries.py → Dictionary examples

▶️ How to Run

Make sure you have Python installed, then run:

python list.py

🎯 Purpose

This project is for beginners who want to understand Python data types with simple examples.
